# 钟乳石洞穴微环境巡测

## 启动

```bash
npm install
npm start
```

默认地址：http://localhost:3912

数据保存在`data/db.json`，后续可以继续增量迭代。

## 游客干扰处置（换班可接手）

游客触碰、越线统一在「干扰处置」标签登记，记录**发现时刻、样点、现场人员、现场照片、现场情况**，处置全程留痕，第二天换班照单接手。

处置队列状态：

1. **待补证**：登记时缺照片，或进入处置后照片仍缺失。补证期限为发现后 24 小时，逾期在队列中按逾期时长置顶；样点保持「重点保护」。
2. **处置中**：照片已齐，等待值班负责人补充现场说明（经过、措施、环境现状）。
3. **待确认**：负责人补完说明后**不能自行结束**，须由另一位巡测员确认环境恢复（系统强制确认人与负责人不是同一人）。
4. **已恢复**：双人确认后结案。样点恢复到干扰前状态——原本「暂停开放」的仍不开放，其他样点恢复原状态。

规则：

- 同一样点存在未结案记录时再次上报，**沿用原记录**并累加 `reportCount`，历次上报（时刻、人员、照片、说明）都挂在同一条记录上，不产生重复单据；结案后再报才新建。
- 处置期间样点锁定「重点保护」，原状态记录在案，结案时自动恢复。
- 队列按"逾期时间"排列：待补证按补证期限、待确认按等待确认时长，卡片上以进度条显示「登记 → 照片补齐 → 负责人说明 → 另一位确认」进行到哪一步。
