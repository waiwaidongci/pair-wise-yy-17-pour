# 钟乳石洞穴微环境巡测

## 启动

```bash
npm install
npm start
```

默认地址：http://localhost:3912

数据保存在`data/db.json`，后续可以继续增量迭代。

## 游客干扰处置记录

游客触碰、越线等干扰按"处置记录"闭环管理，换班后可直接接手：

- **登记发现**：记录发现时刻、样点、现场人员、现场情况和照片；常规样点在处置期间自动升级**重点保护**。
- **再次上报**：同一样点未闭环前再次上报，**沿用原记录**并累加上报次数，补证截止时间不重算。
- **待补证**：照片缺失且超过 24 小时无人补充，记录进入**待补证**，样点保持重点保护；补回照片即脱离。
- **现场说明**：值班负责人补完现场说明后进入**待确认**，但不能自行结束。
- **确认闭环**：须由**另一位巡测员**确认环境恢复。原本**暂停开放**的样点确认后仍不开放，其他样点恢复原来状态。
- **列表排序**：按逾期时间排列——补证逾期最久的在最前，其后是临期补证、待补说明、待确认，已闭环垫底；每张卡片直接显示补证 / 说明 / 确认三段进度。

### 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/incidents/register` | 登记发现；同一样点未闭环时自动沿用原记录并累加次数 |
| POST | `/api/incidents/:id/photos` | 补充照片 |
| POST | `/api/incidents/:id/note` | 值班负责人补现场说明 |
| POST | `/api/incidents/:id/confirm` | 另一位巡测员确认环境恢复并闭环 |

领域逻辑在 `incidents.js`（纯函数，不依赖 Express）。
